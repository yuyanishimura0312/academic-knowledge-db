## 1. 詩派・流派の格納先ルール

C13で「建安七子・竹林七賢・王孟・李杜・韓孟・元白」等を concepts として投入した妥当性が問われた。これに対する判断:

### 規則
- **古典時代の詩派・集団**（前近代の中国・日本・西欧）→ concepts（批評範疇として概念化されてきたため）
  - 例: 建安七子、竹林七賢、初唐四傑、ストア派文学、Pléiade
- **近代以降の宣言的文学運動** → movements（自己定義された組織的運動）
  - 例: ロマン主義、自然主義、シュルレアリスム、五四新文学運動、白樺派
- **判定基準**: 当時の自己定義（マニフェスト・宣言）の有無、組織的活動の有無、後代批評による命名か当時の自称か

### 適用
- C01-C12（西欧）: ルネサンス以前は concepts、啓蒙以降は基本 movements
- C13-C18（東アジア）: 唐以前は concepts、宋元以降の流派は要判断、清末民初以降は movements
- C19-C22（南西アジア）: 古典は concepts、ナフダ運動以降は movements
- 全領域: 不確かな場合は concepts 投入し、Phase 4 で必要に応じて movements に昇格

## 2. 概念結晶時代 vs 源流時代の格納ルール

C13で「点鉄成金（黄庭堅・宋）」「夺胎换骨（同）」が唐以前の手法を結晶化した語であることから、いつのperiodに紐づけるかが問題化。

### 規則
- 概念名の**結晶時代（命名された時代）**を period_id とする
- 起源・先行例は development フィールドに散文記述
- 例: 点鉄成金 → period='北宋', development='杜甫の典故活用を江西詩派が理論化'
- 例: mimesis → period='古典古代ギリシャ', development='プラトンが先行、アリストテレスが体系化'

### 例外
- 真に時代横断的な概念（oral tradition、口承等）は period_id=NULL を許容し、historical_context で複数時代を記述

## 3. 第四変容軸タグ付与の領域別期待値

C13で「物語軸タグ0件」が懸念されたが、これは詩中心領域として自然な結果。領域特性に応じた期待値を明記:

| 軸 | 高期待領域 | 低期待領域 |
|---|---|---|
| 作者性 | 全領域（普遍的軸） | — |
| 創造性 | 全領域（普遍的軸） | — |
| 物語 | 小説・叙事詩・劇・神話領域 | 抒情詩中心領域（中国古典詩、日本和歌） |
| 主体 | 近代小説、私小説、自伝 | 古典詩、口承伝統 |
| 正典 | 古典領域、批評領域 | 現代周縁領域 |
| 受容 | 批評理論、デジタル文学 | 古典の作品単独 |
| 翻訳 | 比較文学、翻訳論、ディアスポラ | 単一言語圏内の理論 |
| 真正性 | 古典学、写本系統論、口承 | 近現代文学（著作権で自明） |
| 言語 | 文学理論、文体論、デジタル文学 | 主題中心の研究 |

### 運用
- 1サブフィールドあたり最低3軸が付与されることを目標
- 9軸全付与は不要（領域特性に逆らうな）
- C40（QA）は領域別期待値とのズレが大きい場合のみ警告

## 4.1 Phase 2 Wave 設計（漸進展開）

API使用量・品質一貫性のため、4ウェーブで漸進展開:

- **Wave 1（完了）**: C01ギリシャ + C13中国古典 = 100 concepts
- **Wave 2（次回）**: 各地域代表4名 = 400-500 concepts
  - C18 日本近現代（東アジア）
  - C21 アラブ（南西アジア）
  - C30 先住民・北米/豪/アイヌ（周縁口承）
  - C39 DH/AI（第四変容核心）
- **Wave 3**: 残り西欧+ロシア+ラテンアメリカ群 約12名
- **Wave 4**: 残り全領域 約20名 + C40横断検証

各ウェーブ完了後にC40スポット監査→次ウェーブ起動。

## 4.2 C01追加の運用ルール

- **並列書き込み時の relations は領域内に限定**: Phase 2では同subfield_id内のみ relations 投入。subfield横断 relations は Phase 3 / Phase 4で集約
- **概念名表記の正規化（lint）**: 投入前に既存concepts に対する表記揺れ検出（半角/全角、繁体/簡体、ローマ字異音等）を helper に追加
- **一次資料URLは章節アンカー任意**: Phase 2は ベースURL のみ必須、章節アンカーは Phase 3 で精緻化
- **第四変容タグは厳選付与**: 概念総数の30-40%程度が品質的に妥当。強制付与は禁止
