# 文学学術知識DB（LIT-DB）構築計画 v0.1

**作成日**: 2026-05-06
**ステータス**: Phase 0 着手前（西村承認待ち）
**オーケストレーター**: academic-db-builder（Opus）+ Codex 20名

---

## 1. プロジェクト概要

### 1.1 目的
枢軸時代→ルネサンス→産業革命を経て、第四の構造変容（AI社会）に入る現在において、文学が積み上げてきた概念体系（作者性・創造性・物語・主体・他者性・正典・受容など）を学術的に再構造化する。とりわけ西欧中心の文学観を脱し、東洋および非西欧圏の文学伝統を対等な知的遺産として位置づけ、概念・背景・系譜・時代文脈を一貫した粒度で記述する。

### 1.2 問題意識
- 生成AIにより「作者性」「創造性」「オリジナリティ」「読者性」が根底から問い直されている
- 既存の文学理論DB（Poetics DB: 1,121概念）は詩学・理論形式に特化しており、作品史・作家・運動・地域横断概念を包括していない
- 西欧中心主義の解体（ポストコロニアル・世界文学論）の知見をDB構造に内在化する必要がある

### 1.3 既存DBとの差別化
| DB | フォーカス | 規模 |
|---|---|---|
| Poetics DB（PT） | 詩学・理論形式 | 1,121概念 |
| Philosophy DB（PHIL） | 哲学概念 | 8-10K目標 |
| Anthropology DB | 人類学概念系譜 | 500概念 |
| **LIT-DB（本件）** | **文学概念・作品・作家・運動・地域伝統の系譜** | **10K概念目標** |

LIT-DBは Poetics の上位包含層として、文学運動・作品史・地域伝統・受容理論・正典形成を扱う。重複概念は Poetics へリンクし二重化を防ぐ。

## 3. 第四変容期の重点概念軸（クロスカット）

全領域に跨る「再考タグ」として付与し、AI時代の概念問い直しを可視化：
- 作者性（auctorship / 作者の死 / AI共著）
- 創造性・オリジナリティ・模倣（imitatio）
- 物語・ナラティブ・反物語
- 主体・主観・他者性
- 正典（canon）と周縁化
- 受容・読者・解釈共同体
- 翻訳・翻案・世界文学
- 真正性（authenticity）と書記
- 言語・文体・声（voice）

## 4. データベーススキーマ（暫定）

既存 academic-db-build 7テーブル構造に準拠＋文学固有拡張：

```
concepts            概念（10K件）
authors             作家・作者（3K件）
works               作品（5K件）：作品単位の独立テーブル（文学固有）
movements           文学運動・流派（500件）
periods             時代区分（地域別）
relations           概念間関係（30K件目標）
geneal_links        系譜関係（影響・継承・批判）
cross_domain        他DBへのブリッジ（PHIL/PT/AN/MG/Era-Talents）
fourth_transform_tags  第四変容期再考タグ
```

`works` テーブルは文学DB固有。哲学・人類学にはない「作品」を一次データとして扱うため。

## 7. 品質基準（哲学DBの教訓を踏襲）

- 一次資料優先: PD原典（Gutenberg / 青空文庫 / CTEXT / 維基文庫 / Sanskrit GRETIL / Perseus 等）から原語情報を取得
- 重複ゼロ: 概念名 + 地域 + 時代の3キーで一意化
- 系譜の双方向リンク: 影響・批判・継承を双方向relation化
- 第四変容タグ: 全概念にAI時代再考軸タグを付与（再考対象 / 不変 / 部分再考の3値）
