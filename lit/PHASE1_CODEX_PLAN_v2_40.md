## 2. 週次マイルストーン（Phase 2 = 20日／4週間に短縮）

20名版（30日／5週間）を40名体制では4週間に圧縮する。並列度が2倍になることでクリティカルパス作業（一次資料アクセス確立、正典リスト作成）の総作業量はC20名分担当時と同等だが、領域ごとの担当者が増えることでサブフィールド内の作業を並列分割可能。

- **Week 1（Day 1-5）**: 正典リスト作成・一次資料アクセス確立・最初の50 concepts/Codex
- **Week 2（Day 6-10）**: 主要収集の上半（concepts 50%・authors 60%）
- **Week 3（Day 11-15）**: 主要収集の下半（concepts 100%・authors 100%・works 80%）
- **Week 4（Day 16-20）**: 関係性記述（relations / geneal_links）・cross_domain リンク・第四変容タグ付与

平均ペース: 11,000 concepts / (39名 × 20日) ≈ 14 concepts/day/Codex（20名版の73 concepts/day から大幅減で品質確保）。

## 3. 領域グループ別調整事項

### 3.1 西欧グループ（C01-C12）

C03/C04の旧負荷集中（1,000-1,600 concepts）が解消され、各員250-500 concepts。最も負荷の重いC10（モダニズム500）でも14日で達成可能。Modernist Journals Project の同時アクセス制限が課題となる場合、C08-C12が時差利用で調整。

### 3.2 東アジアグループ（C13-C18）

中国古典が時代別2名（先秦〜唐 / 宋元明清）になることで、CTEXT・維基文庫の同時利用と、唐詩・宋詞の専門性確保が両立。日本古典も時代別2名で能・連歌・俳諧・近世小説の専門領域化が可能。

### 3.3 南西アジアグループ（C19-C22）

インド古典と近現代を分離し、サンスクリット原典（GRETIL/SARIT）専門のC19と諸言語（タミル・ベンガル・ヒンディー等）専門のC20を分業。アラブ（C21）とペルシア・トルコ（C22）も分離してOpenITI/Ganjoor のフルアクセスを確保。

### 3.4 グローバルサウスグループ（C23-C27）

アフリカとラテンアメリカが時代別2名構成になり、口承・植民地期と独立後・現代が分業。WOLP/PARADISEC のアフリカ口承録音と、Cervantes Virtual の植民地期スペイン語文献を専門担当。

### 3.5 周縁横断グループ（C28-C33）

ロシアの19c黄金時代と銀の時代以降を分離し、ドストエフスキー・トルストイ・チェーホフの密集領域に十分な時間を割ける。先住民は北米・豪・アイヌ系（文字資料豊富）と他文化圏（口承中心）に分業。

### 3.6 理論・横断グループ（C34-C39）

文学理論を時代・学派別3名（古典〜19c / 形式主義系 / ポスト構造主義系）に分割し、SEP・PhilPapers との重複領域でPHIL-DBとの cross_domain を高密度に張る。比較文学/翻訳/AI を3名に分けることで、世界文学論（C38）とAI時代の生成文学（C39）の両極を専門化。

### 3.7 横断QA（C40）

20名版のC20と同じ役割。ハルシネーション検出・source_tier判定・cross_domain整合性検証を専属で担当。Day 5/10/15/20 に中間監査を実施し、各グループに修正フィードバック。
