# LIT-DB Wave別実行計画

## 実証済みパラメータ（Wave 1-3で確立）

- 並列度: **4並列**（C21・C30は2-2で起動）
- スクリプト長: **500-800行**（150行制約は失敗）
- 設計時間: **5分以内に書き始める**

## 完成見込み

- 各Wave: 4並列 × 40 = 160 concepts、約15-20分
- Wave 4-10: 7 waves × 160 = 1,120 concepts追加
- 累積到達: 360 + 1,120 = **約1,480 concepts（規模13.5%）**

これは v0.1段階の主題実証を v0.2 で深化させる中規模リリース。
完全な11K規模は v1.0 として後続。

## 各Wave完了時の処理

1. Phase 3 verifier 実行（領域別品質チェック）
2. Phase 4 cross-subfield 分析（新領域で系譜検出再実行）
3. Phase 4 適用
4. STATUS.md 更新

各Wave完了から次Wave起動まで5分以内。
