# Poetics DB v2.0 — 詩文獲得拡張プロジェクト

## 計画策定日
2026-05-07

## 目的
Poetics DB v1.0（1,494概念・602研究者・1,136関係）に対し、詩学が分析対象としてきた**一次テクスト（詩文）4,000-5,000件**を構造化データとして追加し、理論×実例の双方向参照可能な二層構造を構築する。

## 背景
v1.0は「詩学についての言説」（メタレベル）を網羅したが、ホメロス、サッフォー、『詩経』、『万葉集』、ハーフィズ、ダンテ、シェイクスピア、ボードレールなどの**実際の詩文**（オブジェクトレベル）が不在であった。哲学DB（PHIL）で確立した「PD原典からの一次取得」ルールを詩学領域に適用する。

## スコープ

### 三層包含基準

| 層 | 基準 | 規模 |
|---|---|---|
| 第一層: 正典級 | Princeton Encyclopedia / Routledge Handbook で主題化される正典 | 約1,500件 |
| 第二層: 理論連結 | 既存1,494概念の例証として研究者が引用したテクスト | 約2,000件 |
| 第三層: 多文化補完 | 比較詩学観点での非西欧詩文（西欧偏向の是正） | 約1,000-1,500件 |
| **合計** | | **4,000-5,000件** |

### 文化圏バランス目標
- 西欧（古代ギリシャ・ローマ + 中世 + 近代）: 55%（約2,500件）
- 東アジア（中国古典・日本古典・仏典詩偈）: 25%（約1,200件）
- 南アジア・西アジア（サンスクリット・アラビア・ペルシア）: 15%（約700件）
- アフリカ・先住民・口承・その他: 5%（約250件）

### 著作権ポリシー
- 原則PD（パブリックドメイン）原典のみ
- 20世紀以降の現代詩は版権切れ・CC・引用範囲（批評対象部分）に限定
- すべて`source_url`で一次ソース照合可能とする

## スキーマ（4テーブル）

`01_schema.sql`参照。
- `poetics_text`: 詩文本体（id, title, author_id→researchers, era, culture_region, form_genre, full_text_or_excerpt, source_url, canonical_tier, etc.）
- `poetics_text_translation`: 翻訳（多言語対応）
- `poetics_text_concept_link`: 理論↔実例リンク（concept_id→humanities_concept, discussed_by_researcher_id→researchers, discussion_locus）
- `poetics_text_motif`: モチーフ・テーマタグ
